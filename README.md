## ✨ Fitur Website
* **Desain Responsif Penuh:** Optimal dibuka melalui Smartphone, Tablet, maupun Laptop/Desktop.
* **Mode Gelap & Terang (*Dark/Light Mode*):** Dilengkapi pengubah tema otomatis yang nyaman di mata.
* **Animasi Interaktif:** Efek mengetik (*typing effect*), kartu mengambang (*floating badges*), dan transisi halus saat halaman digulir (*scroll reveal*).
* **Filter Sertifikasi & Prestasi:** Memudahkan pengunjung menyaring 11+ sertifikat berdasarkan kategori (*Teknologi & AI*, *Keagamaan & Kaligrafi*, serta *Kepemimpinan & Organisasi*).
* **Modal Detail Proyek:** Rincian arsitektur aplikasi seperti *Informatika Smart Learning (ISL)* dan *Buku Daftar Nilai Informatika (Google Apps Script)*.

## 🚀 Cara Mengaktifkan di GitHub Pages
1. Unggah file `index.html` ini ke cabang utama (`main`) repositori GitHub Anda.
2. Buka menu **Settings** > **Pages** di repositori GitHub.
3. Pada bagian **Build and deployment**, pilih **Deploy from a branch**, lalu pilih branch `main` dan folder `/ (root)`.
4. Klik **Save**, tunggu 1–2 menit, dan website portofolio Anda siap diakses secara online!
